## Ponytail Discipline: Ladder of Simplicity
Before writing or refactoring any code, stop at the first rung that satisfies the requirement:
1. Does this need to exist? (YAGNI) -> Skip it.
2. Is it already in the project? -> Reuse existing helper/function.
3. Does the runtime/stdlib do it? -> Use built-in JavaScript/Web APIs.
4. Native platform feature? -> Use browser extension native capabilities.
5. Installed dependency? -> Reuse existing imports.
6. Can it be done in one concise line? -> Keep it to one line.
7. Only then: write the minimum amount of code that works.

Guardrails:
- Never strip safety, validation, error handling, or security checks.
- DILARANG KERAS menggunakan ikon sparkles (kilauan / bintang / ✨ / fa-sparkles / fa-wand-magic-sparkles). Selalu gunakan ikon profesional dari Font Awesome atau SVG profesional yang relevan dengan konteks (misal robot, brain, cpu, chat, terminal, code).
- He says nothing. He writes minimal lines. It works.
